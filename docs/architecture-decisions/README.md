# Architecture decisions

This directory contains numbered Architecture Decision Records for durable,
cross-cutting, costly-to-reverse, or externally visible technical decisions.

Copy [`0000-template.md`](./0000-template.md), assign the next unused number, and
set its status to `Proposed`. Accepted ADRs are immutable decision history. Replace
an accepted decision with a new ADR and mark the older record `Superseded`.
