# COD-001.13 Single Maintainer Agent Mode

## Mission

Align the Agent OS governance model with the current operating model: one human maintainer coordinating multiple AI agents.

The repository should optimize for a single maintainer workflow while preserving the ability to introduce branches, reviews, and multi-agent collaboration when needed.

## Context

The previous governance model was designed closer to a multi-contributor engineering team.

The current model is:

- Human owner: architecture decisions and final direction
- GPT Pro: Principal Architect
- Codex: Staff Engineer
- Other agents: implementation and review roles
- GitHub: source of truth and project memory

## Constraints

- Preserve GitHub as Source of Truth.
- Preserve Evidence-based delivery.
- Preserve Local Repository verification rules.
- Do not modify product code.
- Avoid unnecessary governance complexity.

## Expected Outcome

Review and update the relevant governance documents so they accurately describe the current operating model.

The agent should independently determine which files require updates, including but not limited to:

- AGENTS.md
- development governance documents
- branch and delivery protocols
- command guidance

The result should make future agent sessions understand:

- main is the default integration path for a single maintainer workflow;
- temporary branches are used when risk or parallel work requires them;
- agents should operate autonomously within mission boundaries;
- rules should optimize reliability without adding unnecessary process overhead.

## Completion

Provide evidence of updated documents and the final delivery status.
