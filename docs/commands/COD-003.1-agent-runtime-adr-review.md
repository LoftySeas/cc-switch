## Required Content

The ADR must define:

1. Why CC Switch needs an AgentRuntime abstraction.
2. Why Runtime, Provider, Model, Agent, and Role must remain separate concepts.
3. Why Workflow orchestration should not be embedded inside Runtime adapters.
4. Alternatives considered and rejected.
5. Migration impact on existing CC Switch architecture.
6. Risks and future extension considerations.
