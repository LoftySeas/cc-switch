# COD-001.12 Governance Baseline Verification

## Role

Staff Architect / Reviewer

## Objective

Verify that the Agent OS governance foundation has been successfully integrated after PR merge.

This task validates the final remote state only. It does not redesign architecture or modify product code.

## Dependencies

- COD-001.11 governance-baseline-integration

## Validation Scope

Verify the target branch after merge contains:

- `AGENTS.md`
- `CONTEXT.md`
- `docs/vision/`
- `docs/architecture/`
- `docs/architecture-decisions/`
- `docs/commands/`
- `docs/reviews/`
- `docs/development/`

## Required Checks

1. Confirm GitHub remote state.
2. Confirm expected files exist.
3. Confirm documentation links are valid.
4. Confirm no product source code was modified by governance changes.
5. Confirm Agent bootstrap flow is complete.

## Output

Create:

`docs/reviews/governance-baseline-verification.md`

Include:

- verification timestamp
- verified branch
- commit SHA
- checked files
- validation results
- remaining risks

## Constraints

- Do not modify product code.
- Do not introduce new architecture decisions.
- Report missing evidence instead of assuming success.
