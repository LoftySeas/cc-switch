# COD-001.9 Governance Synchronization

## Role

Staff Architect

## Objective

Synchronize Agent OS governance documents between local Agent workspaces and GitHub Source of Truth.

## Context

Previous Agent tasks created some governance documents locally but they were not always committed to GitHub. This task ensures that all required governance rules have a verified remote location.

## Read First

- AGENTS.md
- CONTEXT.md
- docs/development/command-publication-protocol.md
- docs/development/agent-evidence-protocol.md

## Tasks

1. Audit current GitHub documentation state.
2. Identify governance documents referenced by AGENTS.md and initialization instructions.
3. Verify each referenced file exists remotely.
4. If required governance documents are missing:
   - create them with the intended content
   - preserve existing information
   - do not modify product code
5. Update documentation indexes if required.

## Required Documents

Verify availability of:

- docs/development/agent-operation-guidelines.md
- docs/development/local-repository-usage.md
- docs/development/agent-evidence-protocol.md
- docs/development/command-publication-protocol.md
- docs/development/change-management.md

## Constraints

- GitHub is the source of truth.
- Do not assume local files exist remotely.
- Do not report completion without evidence.
- Do not push automatically without authorization.

## Output

Return Git Delivery Status:

- changed files
- current branch
- commit hash
- push status
- remote verification status
- workspace status

Create a review summary after completion.
