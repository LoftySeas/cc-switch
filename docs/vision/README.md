# Vision

This directory defines the durable purpose, principles, target users, desired
outcomes, boundaries, and non-goals of CC Switch Agent OS. Vision documents answer
why the system should exist and what success means; they do not prescribe detailed
implementation.

Vision changes require product and architecture review. Agent-authored vision is a
draft until accountable humans approve it.

## Documents

- [`agent-os-blueprint.md`](./agent-os-blueprint.md) — canonical What/Why statement
  for the Agent OS product Vision, derived from the preserved source blueprint.
